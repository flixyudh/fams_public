# FAMS - Flix App Management System (Public Releases)

This repository serves as the official distribution channel for the **Flix App Management System (FAMS)** build artifacts and releases.

## 🚀 What's in here?

This repository contains the compiled binaries and production builds for:

- **Backend:** The core API services.
- **CLI:** Command-line tools for system management.
- **Frontend:** The web interface (distributed as a production-ready `dist` archive).

## 📦 Getting the Latest Version

You can find all compiled builds in the **[Releases](https://github.com/flixyudh/fams_public/releases)** section of this repository.
